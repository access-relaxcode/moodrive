# MOODRIVE — 음악 반응형 프로그램

음악 파일이나 브라우저 탭 소리에 반응하는 감상·드라이브 웹 프로토타입입니다.

## 실행

`dist` 폴더가 웹사이트 전체입니다. 정적 웹 서버로 이 폴더를 제공한 뒤 브라우저에서 접속하세요.
예를 들어 Python이 설치되어 있다면 저장소 폴더에서 다음 명령을 실행하고 http://localhost:8000 으로 접속합니다.

```sh
python -m http.server 8000 --directory dist
```

탭 소리 연결은 localhost 또는 HTTPS 환경과 오디오 공유를 지원하는 브라우저가 필요합니다. 지원하지 않는 환경에서는 음악 파일을 선택하세요.

## 기능

- 음악 파일 및 탭 소리 연결, 데모 음악
- 감상 모드와 드라이브 모드
- 1인칭, 후방, 측면 드라이브 시점
- 선셋·해변·네온 분위기
- 자동 박자 추정, 리듬 속도 및 효과 강도 조절
- 터치 파형과 전체 화면

현재 버전은 유튜브 URL 직접 입력 기능을 제공하지 않습니다.
음악은 브라우저에서 처리하며, 저장소에는 개인 음악 파일이 포함되지 않습니다.

## 구성

- `dist/index.html`: 화면
- `dist/style.css`: 스타일
- `dist/app.js`: 음악 연결 및 시각 효과
- `dist/beat.js`: 박자 분석

별도 빌드가 없는 HTML/CSS/JavaScript 프로젝트입니다.
